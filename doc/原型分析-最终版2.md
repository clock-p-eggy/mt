## 一、项目概述

### 1.1 核心目标

| 目标类型 | 描述 | 优先级 |
|---------|------|--------|
| **开发周期** | **2-3周内把游戏做出来** | 硬性约束 |
| **质量目标（非强求）** | 游戏时长超过一定标准 | 软性目标 |
| **质量目标（非强求）** | 付费/留存达到一定标准 | 软性目标 |

**核心策略**：采用 MVP（最小可行产品）策略，优先保证核心玩法完整可玩，砍掉所有"中后期"系统。

### 1.2 一句话定位

一款**放置经营（Idle Tycoon）+ 收集养成**的轻量玩法：
- 前期用"孵化仪式感 + 高速金币膨胀"建立爽点
- 中期用"传送带升级 + 地块扩张"驱动成长
- 后期用"挖矿产出变异石（每日限量）+ 变异概率"把成长从纯金币转为**稀缺道具驱动**

### 1.3 核心设计公式

```
放置产出 × 随机惊喜 × 收集成就 × 每日限制 = 休闲放置经营
```

## 二、系统取舍决策

### 2.1 必要复刻的系统（6个）

| 系统 | 说明 | 实现优先级 | 预估工时 |
|------|------|-----------|---------|
| **基本玩法** | 动物园经营核心循环 | P0 | Medium (1-2d) |
| **新手引导** | 3-5分钟引导流程 | P0 | Short (1-4h) |
| **每日签到** | 配表驱动，7天循环 | P1 | Quick (<1h) |
| **商店** | 游戏内购买入口 | P1 | Short (1-4h) |
| **地图商城** | 场景内购买体验 | P2 | Short (1-4h) |
| **付费高级田地** | 3个金币解锁 + 2个金豆子解锁 | P1 | Short (1-4h) |

### 2.2 调整后需要的系统（1个）

| 系统 | 原版问题 | 调整方案 |
|------|---------|---------|
| **图鉴系统** | 界面复杂度高 | 简化为列表形式，降低开发成本 |

### 2.3 明确放弃的系统（9个）

| 系统 | 放弃理由 |
|------|---------|
| 在线奖励 | 每隔120秒给道具，增加服务器复杂度 |
| 每日任务 | 属于"中后期问题"，2-3周开发不考虑 |
| 礼包 | 需要运营配合 |
| 成就 | 图鉴的延伸功能，优先级低 |
| 粉丝福利 | 需要社交媒体联动 |
| 兑换码 | 运营向功能 |
| 离线收益 | 增加挂机属性，可能影响付费设计 |
| 许愿 | 每日变异石+变异宠物，增加复杂度 |
| 排行榜 | 需要服务端支持 |

## 三、核心玩法循环

### 3.1 主循环：经营扩张（金币驱动）

```
                        ┌─────────────────────────────────────┐
                        │           动物园大亨                 │
                        │         核心玩法循环                 │
                        └─────────────────────────────────────┘
                                         │
     ┌───────────────────────────────────┼───────────────────────────────────┐
     │                                   │                                   │
     ▼                                   ▼                                   ▼
┌─────────┐                        ┌─────────┐                        ┌─────────┐
│  购买蛋  │◄──────金币─────────────│ 收取金币 │◄────────定时产出──────│  动物   │
│ ($200+) │                        │ (走入触发)│                        │ (孵化后)│
└────┬────┘                        └─────────┘                        └────▲────┘
     │                                                                     │
     │                           ┌─────────────┐                           │
     └──────蛋放入物品栏──────────►│   孵化过程   │───────左右摇晃───────────┘
                                 │ (空地上放置) │      裂开动效
                                 └─────────────┘
```

**循环拆解**

| 阶段 | 玩家行为 | 系统反馈 | 情绪曲线 |
|------|----------|----------|----------|
| 购买蛋 | 点击传送带上的蛋购买 | 蛋进入物品栏（8格） | 期待感 |
| 孵化 | 在已解锁地块上放置蛋 | 左右摇晃动效、裂开特效 | 紧张+惊喜 |
| 产金 | 被动观看 | 酷炫金币掉落特效 | 满足感 |
| 收取 | 走入动物所在地块 | 金币飞入+数字跳动 | 获得感 |
| 解锁/升级 | 消耗金币 | 新区域开放、数值提升 | 成就感 |

### 3.2 副循环：挖矿→变异（稀缺资源驱动）

```
进入矿场 → 点击挖矿(4.7s CD) → 获得矿石+变异石 → 出售/使用
                                     ↓
                               动物变异(25%成功率)
```

**副循环关键设计点**
- 变异石每日限量（4个/天）
- 挖矿支持双人协作（社交绑定）
- 矿石可出售换取大量金币（$10,950/次）
- 矿场区设有"回收商人"NPC

## 四、最小核心循环（MVP范围）

### 4.1 三大核心功能

| 核心系统 | 功能边界 | 依赖关系 |
|---------|---------|---------| 
| **传送带** | 产蛋、移动、销毁、升级解锁新蛋 | 独立系统 |
| **地块** | 解锁/未解锁状态切换、金币消耗 | 依赖金币系统 |
| **宠物** | 蛋孵化、定时产金币、玩家拾取 | 依赖传送带+地块 |

**完整循环链路**：
```
传送带产蛋 → 玩家购买 → 背包存储 → 解锁地块 → 孵化宠物 → 产出金币 → 升级传送带/解锁更多地块
```

### 4.2 场景布局设计

根据设计图（约 11列 × 7行）：

| 区域 | 颜色 | 位置 | 说明 |
|------|------|------|------|
| 传送带 | 紫色 | 顶部横向 | 蛋生成和移动区域 |
| 升级区 | 蓝色"升"字 | 最左列 | 玩家进入后升级传送带 |
| 未解锁格子 | 蓝色边框 | 主网格区域 | 需要花费金币解锁 |
| 已解锁格子 | 绿色 | 中心偏下 | 默认4格可用 |

**视觉设计要点**：
- **传送带**：石质拱门为起点，蓝色传送门特效，红色箭头指示方向（左→右）
- **未解锁地块**：紫色/粉色杂草覆盖，绿色发光边界线
- **已解锁地块**：黄色干净方形，边缘清晰

## 六、宠物蛋系统详解

### 6.1 蛋的属性配置

| 属性 | 说明 |
|------|------|
| 名称 | 格式：`[稀有度]蛋名称`，如 `[普通]果实蛋` |
| 外观 | 每种蛋独特外观，不同稀有度外观一致但特效不同 |
| 孵化宠物 | 与蛋一一对应 |
| 稀有度 | 1-3三种，生成时随机决定 |
| 售价 | 基础价 × 稀有度倍率 × 折扣倍率 |

### 6.2 稀有度配置表

| 稀有度ID | 名称 | 掉落几率 | 售价倍率 | 名称色值 |
|---------|------|---------|---------|---------| 
| 1 | 普通 | **89%** | 1x | #FFFFFF（白色） |
| 2 | 稀有 | **10%** | 4x | #50D860（绿色） |
| 3 | 至臻 | **1%** | 16x | #FBF77B（金黄色） |

### 6.3 折扣配置表

| 折扣比例 | 掉落几率 | 售价倍率 |
|---------|---------|---------| 
| 原价 | **89%** | 1.0 |
| 6折 | **10%** | 0.6 |
| 1折 | **1%** | 0.1 |

**折扣UI显示**：粉色气泡标签悬浮在蛋名称上方，如 `6折`

### 6.4 蛋的操作流程

#### 购买流程
```
玩家点击传送带上蛋 → 显示购买按钮 → 点击购买 → 扣除金币 
                                               ↓
                          弹出提示："成功购买：[稀有度]蛋名称"
                                               ↓
                                    蛋进入背包并默认选中
```

#### 孵化条件判断

| 条件 | 操作结果 |
|------|---------| 
| 处于已解锁地块 | 点击孵化 → 生成宠物 |
| 处于未解锁地块 | 提示："请先解锁该地块" |
| 不在任何地块 | 提示："请在地块上进行孵化" |

### 6.5 背包系统

| 操作 | 描述 |
|------|------|
| 存储 | 背包有**8个槽位** |
| 选中 | 黄色高亮边框表示当前选中 |
| 举起 | 选中时蛋模型挂接在蛋仔**头顶** |
| 拖出 | 可拖出背包，蛋生成在玩家附近 |
| 背包满 | 蛋放置在蛋仔附近，可交互举起 |

**特别设计**：蛋是"顶在头上"而非"抱在手中"，蛋底部有绿色叶片装饰作为"底座"

## 七、地块系统详解

### 7.1 地块状态机

```
┌──────────┐     花费金币     ┌──────────┐      放置蛋      ┌──────────┐
│  Locked  │ ─────────────► │ Unlocked │ ─────────────► │ Occupied │

     │                             │                           │
     ▼                             ▼                           ▼
 杂草覆盖                     干净方格                     有宠物
 绿色边界                     黄色地面                     产金币
```

### 7.2 地块价格阶梯

| 地块类型 | 解锁价格 | 特点 |
|----------|----------|------|
| 普通地块 | $350 | 基础放置位 |
| 中档地块 | $2,000 | 标准地块 |
| 高档地块 | $40,000 | 后期地块 |
| 超级地块 | 收集20种动物 | 200%→300%收益倍率 |

### 7.3 超级地块系统

| 属性 | 数值 |
|------|------|
| 解锁条件 | 动物收集数达到**20** |
| 基础倍率 | **200%** |
| 升级后倍率 | **300%** |
| 升级消耗 | **$2,500** |
| 特殊效果 | 动物模型变大 |

**设计意图**：
- 用**乘法器**制造"把最强动物放这里"的明确策略
- 解锁条件绑定收集目标，非常适合做中期里程碑

## 十、经济系统

### 10.1 货币体系

| 货币 | 类型 | 主要来源 | 主要消耗 | 设计作用 |
|------|------|----------|----------|----------|
| 金币（$） | 软货币 | 动物产出、出售矿石 | 买蛋、解锁地块、升级、变异 | 主循环增长 |
| 变异石 | 稀缺资源 | 挖矿（每日限4） | 动物变异 | 留存锚点 |
| 矿石 | 副产物 | 挖矿 | 出售换金币 | 即时回报 |
| 珍珠/金豆子 | 硬货币 | 付费获得 | 特权、高级地块 | 商业化 |

#### 蛋与购买

| 物品 | 基础价格 |
|------|---------|
| [普通]初始蛋 | $200 |
| [至臻]初始蛋 | $1,800 |

| [普通]草莓蛋 | $3,500 (7折) |

| 类型 | 价格 |
|------|------|

| 中档地块 | $2,000 |
| 高档地块 | $40,000 |
| 超级地块升级 | $2,500 |

| 指标 | 数值 |
|------|------|

| 阶段 | 策略 | 效果 |

## 十四、风险与优化建议

### 14.1 主要风险

| 风险 | 说明 | 严重度 |
|------|------|--------|
| 变异25%成功率 | 挫败感较强，每日次数受限时更痛 | 高 |
| 金币通胀 | 卖矿石$10,950可能抹平成本曲线 | 中 |
| 后期目标不足 | 仅靠每日4个变异石，可能"3分钟做完就走" | 中 |
| 付费观感 | 挖矿特权翻倍可能被视为P2W | 中 |
| 数值膨胀 | $40,000地块可能造成断层 | 低 |

### 14.2 优化建议

| 问题 | 最小化解决方案 |
|------|----------------|
| **变异挫败** | 增加失败累积进度/保底；或失败返还部分金币 |
| **金币通胀** | 让矿石售价与阶段绑定，或增加金币黑洞 |
| **后期无聊** | 把任务系统扩展成"每日3~5条短任务" |
| **挖矿疲劳** | 把"拿满日限"控制在2~4分钟内完成 |
| **付费观感** | 特权改为"速度翻倍但不提高日限" |
| **数值断层** | 增加$5,000、$15,000等中间档位地块 |
